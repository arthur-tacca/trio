A nursery of sleeping tasks

Start opens a nursery and spawns five tasks; task n sleeps for n seconds. Cancel cancels the nursery, so every task still sleeping is cancelled at its await. The tasks are spawned with start_soon, so they only begin once the parent reaches the end of the nursery block and waits, and Trio runs each batch of newly runnable tasks either forwards or backwards at random.
